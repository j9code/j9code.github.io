Site Analysis

As an equestrian and mapper, I apply these perspectives by using ArcGIS Pro to conduct terrain/hydrology analyses for local horse farm owners upon request.

Sourcing and integrating USGS 3DEP lidar data with county parcel data, I create digital elevation models, slope analyses, and wetness pattern maps using the Topographic Wetness Index.
